# Commandes spéciales

- **/exit**  
  Ferme le client et termine la session.

- **/send <nom-de-fichier>**  
  Envoie un fichier au serveur pour qu’il soit retransmis aux autres utilisateurs.
  Le fichier inazuma.txt dans le dossier du client peut servir a tester cette commande.

# Autres détails

- Les vieux messages du canal sont automatiquement chargés au démarrage.
- Le dossier `downloads` est créé au besoin pour stocker les fichiers reçus.
- Les messages vides sont ignorés lors de l’envoi.
- Besoin d'aucune commande spécial pour compiler.
- Il se peut que l'envoie de fichier bug par moment (cela est très rare) et je n'ai pas trouvé pour quoi cela ce passe.
